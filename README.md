# Coworking backend

## How to run the server

**Clone the repository**:

`$ git clone https://github.com/j-andrade0/COWorking.git`

**Go to** `COWorking/backend`

**Run in terminal**:
1. `npm install`
2.  `npm run start`

**To stop the server, just type Ctrl + C in the terminal**

## How to access Swagger documentation

Now with the server running, open the browser and go to http://localhost:3000/doc/

There you can find all the endpoints.
